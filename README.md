# Student Management System using Java, JDBC & MySQL

A console-based Student Management System developed using Core Java, JDBC and MySQL. This project allows users to manage student records through a menu-driven interface and stores the information in a MySQL database.

# Features

Add Student: Insert a new student record into the database.<br>
View All Students: Retrieve and display all student records.<br>
Search Student: Search for a student using their roll number.<br>
Update Student: Update a student's name and marks.<br>
Delete Student: Delete a student record using their roll number.<br>
Exit: Close the application.<br>

# Technologies Used
Java | JDBC | MySql

# Prerequisites

Before running this project, make sure you have:<br>
1. JDK installed.<br>
2. IntelliJ IDEA or another Java IDE.<br>
3. MySQl Server installed and running.<br>
4. MySQL Workbench (recommended).<br>
5 .MySQL Connector/J JDBC driver.<br>
